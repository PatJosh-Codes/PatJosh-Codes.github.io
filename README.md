# Patience N. Joshua – research website

Static site (HTML/CSS/vanilla JS) for GitHub Pages.

## Deploy
1. Create a repo named `PatJosh-Codes.github.io` and push these files to the root of `main`.
2. Settings → Pages → Deploy from branch → `main` / root.

## Edit
- Text, table values, publication links: `index.html` (search for `[ADD`).
- CV: replace `assets/Patience_Joshua_Academic_CV.pdf`.
- Photos: `assets/images/`.
